# ROOM-X by Piradex

Reverb modal musical (Early Reflections + FDN + banco modal afinado às notas), VST3 / AU / AAX para macOS 10.13+
(Intel e Apple Silicon) e Windows 10/11. Interface em Português e Inglês.
Criador e Desenvolvedor **Ricardo Amorim / Juninho Piradex** · Beatfreak Music · https://www.beatfreakstudio.com

* Código, documentação, testes e instaladores: **[`ROOM-X/`](ROOM-X/)** (ver `ROOM-X/README.md` e `ROOM-X/CHANGELOG.md`).
* Compilação: GitHub Actions → *Build ROOM-X by Piradex (macOS + Windows)*.
* `legacy-reverbex/`: o ReverbEx antigo (v1, JUCE 7), guardado só como arquivo. Já não é compilado nem distribuído.
