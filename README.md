# reverbex-piradex

Repositório do **ROOM-X by Piradex** (reverb modal musical).

Todo o projeto está em [`ROOM-X/`](ROOM-X/README.md):

- código e documentação do plugin (`ROOM-X/Source`, `ROOM-X/docs`);
- testes (`ROOM-X/tests`);
- pipeline de compilação (`.github/workflows/roomx.yml`, executado para alterações em `ROOM-X/**`).

A versão antiga da raiz (projeto JUCE de teste "ReverbEx") foi removida; continua disponível no histórico do Git.
